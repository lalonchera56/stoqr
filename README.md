# STOQR

Sistema de inventario y ventas con códigos QR para una tienda familiar de ropa. Proyecto Integrador desarrollado en la Universidad Politécnica de Sinaloa (UPSIN).

## Módulos

- **Dashboard:** resumen de ventas, existencias y actividad reciente con gráfica de ventas.
- **Inventario:** catálogo de productos con categoría, talla, precio y existencias, y etiqueta con código QR por producto.
- **Ventas:** registro de ventas, venta rápida desde QR y recibo de venta.
- **Escáner QR:** flujo de escaneo de productos para consultarlos o venderlos.
- **Gastos:** control de gastos de la tienda.
- **Rendimiento:** gráficas de pastel y barras sobre el desempeño del negocio.
- **Usuarios:** administración de usuarios del sistema.

## Tecnologías

- HTML5, CSS3 y JavaScript
- [Chart.js](https://www.chartjs.org/) para las gráficas
- [Font Awesome](https://fontawesome.com/) para los íconos
- Google Fonts (Inter)

## Cómo ejecutarlo

No necesita instalación. Descarga el repositorio y abre `index.html` en el navegador (se requiere conexión a internet para cargar Chart.js, Font Awesome y la tipografía).

## Estructura

```
index.html   Estructura y vistas del sistema
styles.css   Estilos
script.js    Lógica: productos, ventas, escáner y gráficas
```
